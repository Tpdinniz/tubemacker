Política de Privacidade

Última atualização: 27 de outubro de 2026

Esta política explica como o TubeMacker ("aplicativo") acessa, usa, armazena e compartilha informações. O TubeMacker é um aplicativo de uso pessoal, instalado e executado no computador do próprio usuário.

1. Uso dos Serviços de API do YouTube

O TubeMacker usa os Serviços de API do YouTube. Ao conectar sua conta, você também está sujeito à Política de Privacidade do Google.

2. Dados que o aplicativo acessa

Com a sua autorização (pelo login do Google), o aplicativo pode:

  • Enviar vídeos ao seu canal do YouTube: somente os cortes gerados pelo próprio aplicativo, com título, descrição, tags e configurações de visibilidade ou agendamento;
  • Ler informações básicas do seu canal, como o nome, para mostrar qual conta está conectada;
  • Ler estatísticas dos vídeos enviados pelo aplicativo (visualizações, curtidas, comentários e retenção), exibidas na aba "Desempenho" e usadas para melhorar a escolha dos próximos cortes.

O aplicativo não lê suas mensagens, contatos, histórico de navegação, e-mails, nem dados de outros serviços do Google.

3. Como os dados são usados

Os dados são usados exclusivamente para as funções descritas acima, a pedido e em benefício do próprio usuário. O TubeMacker não usa os dados para publicidade, não cria perfis de usuários e não vende nem aluga informações.

4. Armazenamento e segurança

  • As credenciais de acesso (tokens de autorização), as configurações e o histórico de cortes ficam salvos somente no computador do usuário, na pasta %LOCALAPPDATA%\TubeMacker.
  • O TubeMacker não possui servidores próprios e não envia dados ao desenvolvedor.
  • Os vídeos baixados para gerar os cortes ficam no computador do usuário e podem ser apagados automaticamente pelo aplicativo.

5. Compartilhamento com serviços de terceiros

Para funcionar, o aplicativo se comunica diretamente com os serviços abaixo, sempre a partir do computador do usuário e apenas quando ele os configura:

  • YouTube / Google: envio de vídeos e consulta de estatísticas, como descrito acima;
  • Provedor de inteligência artificial escolhido pelo usuário (Anthropic Claude ou Google Gemini): recebe a transcrição de vídeos públicos dos canais acompanhados, para indicar os melhores trechos. Nenhum dado da conta do YouTube do usuário é enviado à IA;
  • Telegram, Instagram e TikTok, somente se o usuário ativar essas integrações: recebem os cortes aprovados pelo usuário e as mensagens de aviso.

Cada um desses serviços tem a própria política de privacidade. O TubeMacker não compartilha dados com nenhuma outra parte.

6. Como revogar o acesso e apagar seus dados

  • No aplicativo: aba Contas › Desconectar. A credencial salva é apagada do computador.
  • Na sua conta Google: acesse myaccount.google.com/permissions e remova o acesso do TubeMacker. O Google descreve esse processo na página de configurações de segurança.
  • Para apagar todos os dados locais, desinstale o aplicativo e exclua a pasta %LOCALAPPDATA%\TubeMacker.

Estatísticas obtidas pela API do YouTube não são guardadas por mais de 30 dias sem atualização: o aplicativo as renova periodicamente enquanto está em uso e apaga automaticamente as que passarem desse prazo.

7. Crianças

O TubeMacker não se destina a menores de 18 anos e não coleta intencionalmente dados de crianças.
